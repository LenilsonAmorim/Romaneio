2. Regras de roteirização

Cadastre cada bairro uma única vez. Não precisa importar a planilha para cadastrar. Depois, qualquer planilha usa automaticamente essas regras.

Cada linha é uma parada. Para quadras, use LETRA + NÚMERO (D1, D2, D9, D10). No endereço também reconhece QD-D5, QD-A1, QD-01, QD 01 e outras formas comuns. Para ruas, escreva o nome completo. O texto de cada linha é salvo inteiro e, quando for uma quadra, a sequência cadastrada é usada para ordenar as paradas.

Editar bairro + variações + sequência

Cada linha é uma parada. Para quadras, use LETRA + NÚMERO (D1, D2, D9, D10). No endereço também reconhece QD-D5, QD-A1, QD-01, QD 01 e outras formas comuns. Para ruas, escreva o nome completo. O texto de cada linha é salvo inteiro e, quando for uma quadra, a sequência cadastrada é usada para ordenar as paradas.

Editar / escrever novamente

Cada linha é uma parada. Para quadras, use LETRA + NÚMERO (D1, D2, D9, D10). No endereço também reconhece QD-D5, QD-A1, QD-01, QD 01 e outras formas comuns. Para ruas, escreva o nome completo. O texto de cada linha é salvo inteiro e, quando for uma quadra, a sequência cadastrada é usada para ordenar as paradas.

Na sequência, digite somente letra + número, por exemplo: D1, D2, D5, D10, D30. A ordem que você escrever será a ordem da sua rota.
